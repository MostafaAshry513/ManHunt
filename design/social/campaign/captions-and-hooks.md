install line somewhere in the same asset.

| CTA-08 | If you play this weekend, tell me how it went. | Feedback posts | Requests honest feedback, never a testimonial or a rating |

CTA rules: one CTA per post (plus the bio link); CTA always states the honest install path when it asks for
a download; never "download now", "last chance", "free forever", "grab it before it's gone"; never ask for
likes/upvotes/follows-for-follows; never put the same link in 5 comments (platform spam filter).

### 4.5 Arabic layout / RTL notes

1. **URLs and code strings stay LTR**, on their own line, never inside an Arabic sentence — wrap them in
   a separate paragraph or place them at the end. Room codes are Latin digits/letters (e.g. `ABC123`).
2. **Western digits** everywhere (`2`, `6`, `8+`, `2 MB`), not Arabic-Indic numerals; never mirror a timer
   or a clock.
3. Keep the product name `ManHunt` in Latin, isolated with spaces or line breaks; never add Arabic affixes.
4. Hashtags: Arabic tags with `_` render right-to-left fine, but keep a Latin tag (`#Android`) separate;
   don't split one tag across a line.
5. Arabic strings are often shorter but wider; re-check on a 360 dp phone and at 1.5× text scale. If it
   doesn't fit, cut a beat — never shrink type below readable size.
6. Don't transliterate the slogan, don't translate it word-for-word, don't mix registers in one asset.
7. Have a native speaker review every string: the bar is "reads like Arabic", not "translates the English".
8. External Arabic copy: prefer `المطاردون` (the chasers) over `الصيادون`; use `مطاردة` for the match,
   `غرفة` for room, `الفريسة` for Prey, `وسم` for tag — as the brand workstream defines.

## 5. Comment reply scripts (FAQ)

Reply as the developer, plainly, once, without repeating the link five times. If a question repeats,
answer it in a video instead (that becomes CAP-08's format).

| ID | Question | Reply |
|---|---|---|
| FAQ-01 | "Is it on iPhone?" | "No iOS version right now — Android 8+ only. I'd rather say that up front than have you install something that doesn't work." |
| FAQ-02 | "Play Store?" | "Not on Google Play. It's a free signed APK from the install page (link in bio) — you allow unknown sources once. The SHA-256 is on the page, and the source is on GitHub." |
| FAQ-03 | "Is my location safe?" | "Your position is shown only to the Hunters in your room during a match; Admins get no extra location power; there's a foreground notification. It's a game, not a safety service, and the hosted server is a test server over plain HTTP — don't use it for sensitive location data. Play with people you trust." |
| FAQ-04 | "Does it cost anything?" | "Nothing. No ads, no purchases. It's MIT licensed and open source." |
| FAQ-05 | "How many people?" | "2+ phones minimum; 3–8 is a good first game. Everyone joins the same room with a 6-character code." |
| FAQ-06 | "Battery?" | "GPS runs during a match via a foreground service, so it will use battery — bring a power bank for long games. Field battery life isn't verified on physical phones yet." |
| FAQ-07 | "Does it work offline?" | "No. Phones need network to the server during the hunt, and the map tiles need network too." |
| FAQ-08 | "Does it record me / use my camera?" | "No camera or mic features. It uses location (during a match), network, notifications, and the in-app update installer." |
| FAQ-09 | "Is this a stalking/tracking app?" | "No. It's a game a group agrees to play together: only Hunters in your room see positions, only during a match. Don't use it to track anyone — and don't meet strangers to play; build a room from people you already know." |
| FAQ-10 | "How do I join?" | "Home → Join a hunt → enter the 6-character code → pick Prey or Hunters → Ready to hunt. The host starts the head start." |

### 6.3 Safety and legal requirements per post

1. **Consent:** everyone identifiable on camera consents to being filmed and posted. Minors: guardian
   consent, and don't target minors in the content or the targeting.
2. **Location privacy:** blur house numbers, plates, school/hospital signs; don't show a real person's home
   on the map; film in public parks/streets.
3. **Play context:** public places you're allowed to be in; daylight or well-lit for filmed games; no
   trespass, no roads/rails/construction/water, no "hide in the mall after closing" jokes, no police/
   siren framing, no alcohol framing.
4. **Disclosure line** (bio + pinned comment): "Free test build, Android only, not on Play Store. Location
   is shared with Hunters in your room during a match. It's a game, not a safety service — play with
   people you trust."
5. **Install safety:** only the official install page/GitHub release; never APK mirrors/aggregators; mention
   the SHA-256 exists.
6. **No stranger matchmaking:** the game is in person with people you already trust — never invite strangers
   to meet for a hunt; never promote a "find a random hunt" feature.
7. **Platform rules:** no engagement bait, no vote/upvote requests, no auto-DM, no bought engagement, no
   "follow for part 2". Dangerous-activity and minor-safety policies apply — show the safe context.
8. **OSM attribution:** wherever map tiles appear, credit "© OpenStreetMap contributors".
9. **No fake urgency/countdowns:** a clock in the video must be the game's real clock; no invented
   countdowns or "last chance".
10. **Test-server honesty:** where a URL is shown, the hosted deployment is a test server on plain HTTP —
    don't call it secure, don't imply availability guarantees.

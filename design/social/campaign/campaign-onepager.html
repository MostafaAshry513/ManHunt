The one thing strategy

One phone can't play. The campaign converts groups, not individuals — every asset's primary call to action is “send this to the group chat”, and the download is secondary.

The product's own funnel leaks before marketing matters: 48 rooms created, only 6 matches started. Content has to show the room-code moment and real groups playing, or traffic lands in a lobby and leaves. So the order is: fix activation → seed local clusters → measure matches, not "buy reach".

What we can actually measure no analytics SDK

Install page

Live “accounts created” and “new this week” stats at the hosted server. Snapshot daily; includes test accounts.

Server request log

logs/server.out.log records request URLs — including query strings. Filter utm_campaign=launch14 for tagged visits; /app.apk is directional.

Game database

Read-only queries on users, rooms with ≥2 members, matches started/finished and tags — the only trustworthy funnel.

Attribution is directional, not precise: no cookies, no user IDs, shared devices, scanner noise, log rotation. Report tagged visits as a floor and label test accounts. Success in 14 days is one real group finishing one real hunt — not follower count.

Honest expectations new account · $0 budget

  • Median first posts: roughly 100–500 views on a new TikTok account. A first post can outperform; that is luck, not a forecast.
  • Follower growth: 0–50 in 14 days is the realistic range. One video over 10k views is an outlier.
  • Conversion cap: viewers must own an Android phone, have a friend present, and accept a sideload. Base case: 4–9 rooms with 2+ members, 2–5 matches started.
  • Fail signal, day 8: median views <100 and 0 tagged visits and 0 new accounts → change the hook and first frame, not the posting volume.
  • No paid spend before day 8; no app-install ad formats exist (the app is not on Google Play) — only traffic ads to a plain-HTTP test page. Optional paid test is capped at $100.
  • No public stranger matchmaking: a GPS game that pairs strangers is a safety liability. The game is in person, with people you already trust.
  • No fake anything: no testimonials, player counts, reviews, store badges, privacy/safety promises, fake urgency, purchased followers or engagement pods.
  • No spam: disclose you are the maker, read each community's rules, one post per community, never mass-DM download links.

## 3. Exact commands

Run from `C:\dev\ManHunt\design\social\motion`.

```powershell
# Full deterministic build: audio -> 450 master frames + 90 cut frames -> stills -> MP4/WebM/GIF
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1

# Re-encode only (frames already on disk):
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1 -SkipFrames

# Individual steps:
node tools/audio.mjs
node tools/capture.mjs frames master out/frames/master
node tools/capture.mjs frames cut out/frames/cut
node tools/capture.mjs still out/stills/cover.png --url "cover=1"
node tools/capture.mjs still out/stills/poster.png --url "t=0.9"

# Preview the source animation (auto-plays, loop):
node tools/serve.mjs
#   http://127.0.0.1:4173/src/index.html            (live preview)
#   http://127.0.0.1:4173/src/index.html?t=5.6      (frozen frame)
#   http://127.0.0.1:4173/src/index.html?guides=1   (safe-area overlay)
#   http://127.0.0.1:4173/src/index.html?cover=1    (cover layout)
```

The exact ffmpeg commands (also inside `tools/build.ps1`), with `$ff = C:\dev\ManHunt\design\.tools\node_modules\ffmpeg-static\ffmpeg.exe`:

```powershell
# MP4
& $ff -y -hide_banner -loglevel warning -framerate 30 -i "out/frames/master/frame_%05d.png" `
  -i "out/audio/manhunt_score.wav" `
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -profile:v high -level:v 4.2 `
  -c:a aac -b:a 192k -ar 48000 -af "loudnorm=I=-16:TP=-1.5:LRA=11" `
  -movflags +faststart -shortest "out/manhunt_short_1080x1920.mp4"

# WebM
& $ff -y -hide_banner -loglevel warning -framerate 30 -i "out/frames/master/frame_%05d.png" `
  -i "out/audio/manhunt_score.wav" `
  -c:v libvpx-vp9 -crf 34 -b:v 0 -row-mt 1 -pix_fmt yuv420p `
  -c:a libopus -b:a 96k -ar 48000 -af "loudnorm=I=-16:TP=-1.5:LRA=11" `
  -shortest "out/manhunt_short_1080x1920.webm"

# GIF cutdown (128-colour palette, bayer dither, loop forever)
& $ff -y -hide_banner -loglevel warning -framerate 15 -i "out/frames/cut/frame_%05d.png" `
  -vf "scale=720:1280:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128:stats_mode=diff[p];[s1][p]paletteuse=dither=bayer:bayer_scale=3" `
  -loop 0 "out/manhunt_cutdown_720x1280.gif"
```

## 4. How the source is organised

```
src/index.html      stage markup: asphalt, dot grid, chalk geometry, app render insert, clock, captions, end card, cover
src/styles.css      PICKUP design system: palette tokens, flat type scale, safe area, clock, captions, end card
src/animate.js      timeline + beats; window.renderAt(t) is a pure function of virtual time (deterministic)
src/map.js          seeded generator for the block map + dot grid (seed 20261101)
src/field.js        seeded generative "players on the field" traces (seed 1409)
src/fonts/*         (imported from ../assets/fonts) Big Shoulders / Instrument Sans / Red Hat Mono, SIL OFL
assets/fonts/       bundled fonts + their OFL licence files
assets/05-map-crop.png   crop of the ManHunt-owned docs/screenshots/05-hunting-map.png used in beat 4
tools/capture.mjs   headless-Chrome CDP frame/still capture (also serves the folder on 127.0.0.1:4173)
tools/audio.mjs     original score generator (sines/noise/filters -> PCM16 WAV)
tools/serve.mjs     zero-dependency preview server
tools/build.ps1     one-command rebuild of every deliverable
```

**Determinism:** the page exposes `window.renderAt(t)`; every element is re-styled from `t` on each call, so frames can be captured in any order and re-rendered identically. There are no CSS transitions or `requestAnimationFrame` dependencies in capture mode (`?capture=1` freezes the clock; `?t=` paints a still).

2. **Official identity lockup:** source of truth is `design/brand/identity/final/` (`LOCKUP.md`). Motion consumes the light-on-dark set: `lockup-stacked-light-on-dark.svg` (end card) and `wordmark-light-on-dark.svg` (cover header, hook bug). To update: copy the new canonical SVG markup in verbatim, update the sha256 map in `MH_LOCKUP` (`src/animate.js`), adjust only the container size in `styles.css` (`#endWordmark svg` 640 px wide; `#coverTop` 400 px; `#hookBrand .hb-name` 300 px), then rebuild. **Never retype, re-letter-space, recolour, outline or rotate the wordmark**, never put the slogan or any text inside the lockup, and keep the baked-in clear space empty (slogan/CTA must sit outside the SVG box). ## 8. Known limitations / notes for the Lead

1. **Headless capture is the slow step:** ~1.1 s per 1080×1920 PNG on this machine (450 master + 90 cut frames ≈ 10 min). Fine for a rebrand, not for iteration.
2. **Frames were deleted after the build** to keep the workstream folder small (8.8 MB total now); `tools/build.ps1` recreates them.
3. **The app map screenshot is a Robolectric render with a blank OSM tile layer** (per `README.md`: "a render captured without network shows a blank tile layer"). It is the real ManHunt hunting-map UI but not live GPS gameplay; the OSM credit is carried anyway. If a fresh full-map emulator screenshot is available, re-crop `assets/05-map-crop.png` and re-render beat 4 for more realism (the crop is 1117×1162 from the top map card).
4. **Audio is a deliberately restrained synth bed** (chalk scratch, sub pulse, ticks, ping, snap, silence on the end card, per the brand beat sheet). It is original and royalty-free but it is not a music track; a licensed/picked track can replace it by swapping `out/audio/manhunt_score.wav` and re-running the encode steps.
5. **Arabic/RTL is not rendered.** `captions.md` has proposed Arabic lines using the app's own terminology, but an RTL layout pass is needed before shipping an Arabic cut.
6. **Slogan approved; one typography open item.** "No gear. No fee. Just players." is owner-approved and is what the shipped renders use. `LOCKUP.md` §5 says live slogan copy is set in the brand display face; this film sets it in Instrument Sans on the end card (the typography brand-director signed off in v2) and in Big Shoulders on the cover. Left unchanged in task-37 to avoid re-opening a signed-off card — flag to brand-director/owner if the end-card slogan should be re-set in Big Shoulders (one CSS edit + re-render).
7. **MP4 is 1.61 MB / 15 s**, which is fine for Reels/TikTok/Shorts; the WebM (0.82 MB) is the lighter web/install-page option. The GIF is silent by nature.
8. **No platform is claimed.** The end card says "not on Play Store"; install is a sideloaded APK at `http://74.208.99.178/`, and no safety/rescue/trespassing claims or fake social proof appear anywhere.
9. **Identity markup is inline, not a runtime asset.** The official SVG paths are inlined verbatim in `src/index.html` (per `LOCKUP.md` §1) instead of being loaded as a file, so there is no external asset to go missing at render time. If the identity package is re-issued, re-inline the canonical SVG markup, update the two sha256 values in `MH_LOCKUP`, and rebuild.

```powershell
$OUT = 'out/v4-preview'   # versioned output root

# MP4
& $ff -y -hide_banner -loglevel warning -framerate 30 -i "$OUT/frames/master/frame_%05d.png" `
  -i "out/audio/manhunt_score.wav" `
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -profile:v high -level:v 4.2 `
  -c:a aac -b:a 192k -ar 48000 -af "loudnorm=I=-16:TP=-1.5:LRA=11" `
  -movflags +faststart -shortest "$OUT/manhunt_short_1080x1920.mp4"

# WebM
& $ff -y -hide_banner -loglevel warning -framerate 30 -i "$OUT/frames/master/frame_%05d.png" `
  -i "out/audio/manhunt_score.wav" `
  -c:v libvpx-vp9 -crf 34 -b:v 0 -row-mt 1 -pix_fmt yuv420p `
  -c:a libopus -b:a 96k -ar 48000 -af "loudnorm=I=-16:TP=-1.5:LRA=11" `
  -shortest "$OUT/manhunt_short_1080x1920.webm"

# GIF cutdown (128-colour palette, bayer dither, loop forever)

  -loop 0 "$OUT/manhunt_cutdown_720x1280.gif"
```

## 4. How the source is organised

```
src/index.html      stage markup: asphalt, dot grid, chalk geometry, tokens (coral Prey + 5 violet Hunters), clock, captions, end card, cover, official lockup inline SVG
src/styles.css      PICKUP design system: palette tokens, flat type scale, safe area, clock, captions, end card
src/animate.js      timeline + beats (hook/teams/clock/chase/tagged/end); window.renderAt(t) is a pure function of virtual time
src/map.js          seeded generator for the block map + dot grid (seed 20261101)
src/field.js        seeded generative "players on the field" traces (seed 1409)
src/fonts/*         (imported from ../assets/fonts) Big Shoulders / Instrument Sans / Red Hat Mono, SIL OFL
assets/fonts/       bundled fonts + their OFL licence files
tools/capture.mjs   headless-Chrome CDP frame/still capture (also serves the folder on 127.0.0.1:4173)
tools/audio.mjs     original score generator (sines/noise/filters -> PCM16 WAV)
tools/serve.mjs     zero-dependency preview server
tools/build.ps1     one-command rebuild of every deliverable (-OutDir out/v4-preview for versioned builds)
```

**No screenshot / no OSM:** the old `assets/05-map-crop.png` and `assets/05-hunting-map.png` are deleted. The film contains only original generated geometry and drawn vector; there is no third-party map data, so no OSM attribution is required.

**Determinism:** the page exposes `window.renderAt(t)`; every element is re-styled from `t` on each call, so frames can be captured in any order and re-rendered identically. There are no CSS transitions or `requestAnimationFrame` dependencies in capture mode (`?capture=1` freezes the clock; `?t=` paints a still).

# INSPIRATION — references, anti-references, and how to use them

**The rule first:** references are **languages to study, never assets to copy**. Every page must be original
vector/CSS work built from the approved mark, the three OFL faces, and the tokens. **No stock images, no
AI-generated imagery, no network assets, no screenshots of other products, no traced/recut logos or kit** may
appear in a direction page. If you can name the product a page is imitating, it has failed axis 2.

This file is deliberately short: each reference is one line of "what to take" + one line of "what not to take".
Study these territories in the abstract (proportion, hierarchy, material logic, typographic behaviour), then
translate them into ManHunt's own props: **Board, team sheet, code plate, field diagram, field log, hud, score page.**

---

## 1. Field sports & matchday print (direction A territory)

| Reference | Take | Don't take |
|---|---|---|
| **Stadium scoreboards** (dot-matrix/7-seg era and modern LED) | the clock as the loudest object; high contrast numerals; state word + data in a fixed grid; legible at distance/thumbnail | the scoreboard *look* as decoration; scanline/LED cosplay; fake dot-matrix texture over type |
| **Matchday programmes / team sheets** | two-column roster, kit numbers, ruled sections, a masthead with date/time/venue, honest data density | club crests, sponsor blocks, period pastiche (sepia, 70s serif), photocopy texture as a gimmick |
| **Referee/field equipment** (whistles, cards, scorecards, chalk lines) | the physical object logic: a card that signals a state, a chalk line that defines a boundary, one decisive colour per meaning | literal skeuomorphism (leather, metal, stitching) that breaks the flat system |
| **Athletics results sheets / timing boards** | tabular numerals, `MM:SS`, result columns, "FULL TIME"/"DNF" honesty in labels | dense spreadsheet look in interactive pages; mono for prose |
| **Orienteering maps & control cards** | the field diagram as the product; ring/zone + route + control points; measured margins, survey ticks | copying a real orienteering map's symbols/colours; clutter; tiny text to look technical |
| **Pickup sports culture (5-a-side, park run)** | the "borrowed pitch" feeling: tape, chalk, kit bags, phone propped on a bottle; social, warm, ordinary | grit/streetwear pastiche that reads as a fashion brand rather than a game |

## 2. Street posters, stencil & kit graphics (direction B territory)

| Reference | Take | Don't take |
|---|---|---|
| **Screen-printed gig/fight posters** | one big idea per page; oversized display type; flat ink blocks; type as image; no gradients | illegible body type; image-heavy collage; photocopy/xerox noise as texture; illegibility as attitude |
| **Stencil / spray-paint numbering** | a rough, physical numeral treatment; hand-marked labels; stencil as a single accent | fake grunge, drips, overspray decoration; stencil used for essential reading text |
| **Kit/garment graphics** (numbers, names, sponsor-free kit) | jersey/kit numbering scale; name+number hierarchy; cut-corner tags; bold flat colour | real kit manufacturer marks, club crests, league marks; fashion-brand pastiche |
| **Taped/laminated street signage** | layered flat shapes, high-contrast panels, "tonight/here" data blocks; the physical gesture of taping something up | torn-paper filters everywhere; skeuomorphic tape/photos; clutter that hurts scanning |
| **Protest/notice-board typography** | urgency through placement and scale, not exclamation marks; plain commands | fake urgency/scarcity; political slogans; shouty ALL-CAPS body copy |
| **Album/track lists** | typographic rhythm in lists; data rows that feel designed; column alignment | retro music-app pastiche; mono everything |

## 3. Field instruments & navigation (direction C territory)

| Reference | Take | Don't take |
|---|---|---|
| **Rugged GPS/outdoor devices** (handheld, bike computers) | data hierarchy: primary number, secondary context, tertiary label; mono data; measured margins; calm density | surveillance/military reading (the brand rejects it); tiny text everywhere; eighties-tech chrome |
| **Orienteering compass / roadbook** | direction and distance data; hairline grids; honest labels; the map as hero | decorative compass roses, fake bearings, invented coordinates |
| **Aircraft/vehicle instrument panels** | state bands, clear mode indication, everything in one glance; colour reserved for meaning | dashboard cosplay; warning-colour decoration; dense for density's sake |
| **Survey/map marking tools** | survey ticks, registration marks, coordinate plates, legend discipline | surveyor pastiche on every page; grid lines behind text |
| **Printed field guides / manuals** | ruled sections, numbered steps, "what to do" clarity, body copy that reads like a person wrote it | clipped industrial labels; enterprise dashboard neutrality (C's main risk) |

## 4. Game HUDs & in-game interfaces

| Reference | Take | Don't take |
|---|---|---|
| **Tactical/objective HUDs** (one clear objective + status) | one objective at a time; status words; minimal chrome; data near the action | crosshair/reticle/scanline/sci-fi cosplay; military vocabulary; neon-on-black with glow |
| **Sport-game scoreboards / broadcast lower-thirds** | the score/time strip as an object; event moments (full time) as designed screens; team colours with names | broadcast chrome as decoration; replay/transition wipes unrelated to the event |
| **Board-game score pads / tally sheets** | tally marks, roster tables, physical scorekeeping; honest numbers | fake dice/wood/felt textures; skeuomorphism |
| **Horror/stealth chase games** | the tension of "they're closing in" through layout and timing, not gore | horror imagery, blood, weapons, threat language; anything that makes a real park feel unsafe |
| **Navigation apps** | the map as the primary surface; controls that don't fight gestures; attribution discipline | copying a specific map app's chrome; Google/Apple map look; invented map detail |

## 5. Dark UI, editorial & print systems

| Reference | Take | Don't take |
|---|---|---|
| **Dark editorial/tabloid layouts** | strong display headlines on dark ground; hairline grids; generous negative space; type carrying hierarchy | pure black + neon; low-contrast grey-on-grey "premium dark"; oversized empty hero sections |
| **Museum/exhibition wayfinding** | large quiet type; measured spacing; labelled sections; one message per panel | gallery labels everywhere; tiny captions for essentials |
| **Type specimen sheets** | the scale ladder as a design tool; one family doing many jobs; explicit size/tracking logic | specimen decoration; 6 fonts in one page |
| **Technical documentation / field manuals** | numbered procedures, ruled groups, plain language, warnings that look like warnings | legalistic walls of text; enterprise grey dashboards |
| **Night photography of city/parks** | the *idea* of the field as a dark surface with light markings, wet asphalt, street-light pools | photographic textures, glows, bokeh, actual photos (not allowed) |
| **Chalk/charcoal mark-making** | a drawn, slightly imperfect line as a brand gesture; the unclosed ring; survey ticks | hand-drawn "quirky" fonts; scribble texture on text; craft pastiche |

## 6. Anti-references (do not produce these)

**Generic mobile/SaaS:** 20 dp card stacks; tinted icon tile + bold title + grey subtitle repeated; equal-weight
dashboards; five icon-only tabs; pill buttons; floating action button; glassmorphism; "premium dark" gradient
cards; centered grey empty states; Material default dialogs/spinners; purple-blue AI gradients.

**Gamer/tactical cliché:** neon HUDs, scanlines, crosshairs as brand, hexagon grids, "TACTICAL" eyebrow labels,
glowing rings, sci-fi radar cosplay, military ranks, threat/weapon language, "survivor" language; anything that
reads as surveillance for a location-sharing game (the brand explicitly rejects this — `design/redesign/direction.md`
Territory C was rejected for this reading).

**Stock/AI/network:** photographs of people playing, AI-generated "night park" imagery, stock icons/illustrations,
screenshots or traces of other products, map tile screenshots without OSM attribution, brand/kit/federation marks,
emoji as iconography, lorem ipsum, fake logos/sponsors.

**Cheap shortcuts:** fake clocks/player counts/ratings/store badges; "locked"/"pro" upsells; fake urgency;
text shadows/letter-spaced small caps as decoration; 3D/bevel/emboss; torn-paper/photocopy textures; every
section marked with an ALL-CAPS eyebrow; every page stamped with the same graphic gimmick.

## 7. How to translate a reference into ManHunt (matrix)

| If you respond to… | The ManHunt move is… | Where it can live |
|---|---|---|
| stadium scoreboard | the Board strip: state + huge tabular clock + one data gutter | Home (masthead variant), Lobby, Hunt, Result |
| match programme / team sheet | two-column TeamSheet with kit-tag heads and 56 dp ruled rows | Lobby, hunt details, result |
| referee card / whistle | a single state moment as a designed beat (claim sheet, full time) not a dialog | claim, result, pause |
| chalk on asphalt | FieldPlate ring/ticks/survey marks + 1 px ChalkRules as structure | Auth, Home, Roles, empty states |
| orienteering control card | the code as a six-cell plate; zone ring; honest distance/interval data | Lobby, Home join, Hunt |
| street poster | one oversized display idea per page, flat colour blocks, celebratory result/tag moments | Result, Tag claim, Auth, Home |
| field instrument | mono data, hairline precision, calm HUD, map-first hunt | Hunt, Settings, Room rules |
| field manual | ruled sections and plain commands for settings/rules | Settings, Roles, Room settings |
| night city | dark-first ground; the screen as the brightest object; one light gesture per page | all dark pages |
| type specimen | an explicit ladder: display / headline / body / data / state; one family per job | every page's NOTES/tokens |

## 8. Reference hygiene for the review

- A direction's originality is judged on **digested** references: can a reviewer see the ManHunt idea first and
  the influence second (or not at all)? If the influence is the idea, score 2 on distinctiveness.
- Record in `NOTES.md` the 3 references each direction actually used and what was taken from each; that makes the
  "original vs copied" judgement fair and auditable.
- No reference asset goes into a page file. Build the gesture yourself with SVG/CSS and the approved mark/fonts.
- The owner is judging three *ManHunt* directions side by side — references that pull you toward "sports app",
  "festival poster" or "military HUD" are warnings, not targets.

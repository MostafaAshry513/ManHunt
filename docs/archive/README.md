# Archived process records

These files are historical records of how an earlier phase of the project was run by an
AI-assisted team. They are **not** product documentation and are not kept up to date:

| File | What it was |
|---|---|
| `AUTONOMOUS_PROGRESS.md` | A running diary of review/fix passes with per-pass test counts and status |
| `IMPLEMENTATION_PLAN.md` | The old phased plan (most phases it lists as pending/blocked are long done) |
| `TEAM_PLAN.md` | Ownership table for the AI working session |
| `TEAM_TASKS.md` | Task board for that session |
| `TEAM_DECISIONS.md` | Session-level decisions (model assignment etc.) |
| `SKILLS.md` | Catalogue of agent skills used during that session |
| `SKILL_MATRIX.md` | Mapping of those skills to platform research |

They are retained only so history is not rewritten. For the current documentation, start at
[`../README.md`](../README.md).

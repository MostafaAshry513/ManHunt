## Upload notes

- Animated avatars are only supported by some platforms (Discord/Telegram); use static PNGs
  elsewhere.
- YouTube channel art has a 1546×423 safe area; consume the safe-area proof in the kit.
- Instagram/TikTok have no channel header uploads; the 1080×1080 / 1080×1350 cards are
  profile-adjacent assets, not fake banners.
- Install is a sideloaded APK (not on Google Play); keep that disclosure honest everywhere.
- After replacing the OG image, re-run the X/Facebook/Telegram card validators; scrapers cache.
